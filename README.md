# Aathichoodi Academy – Modern Responsive Website

A multi-page React + Vite website for Aathichoodi Academy.

## Pages
- Home
- About Us
- Programs
- Activities
- Gallery
- Admissions
- Contact

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
npm run preview
```

## Before publishing
- Replace the placeholder phone number.
- Confirm the address and opening hours.
- Connect the enquiry form to email, WhatsApp, or a backend.
- Review all gallery captions and program details.
